# ОВДП Hub

Агрегатор публічної інформації про облігації внутрішньої державної позики України. Порівняння повної вартості та дохідності з розрахунками на пристрої користувача.

**Статус: прототип 0.1.0. Усі пропозиції синтетичні. Реальні джерела ще не підключені. Купівля та персональні рекомендації відсутні.**

## Принцип приватності

Немає користувацьких акаунтів, серверної бази портфелів, KYC чи завантаження документів. Бюджет і розрахунки залишаються в браузері. Прототип не зберігає їх після перезавантаження. Майбутні персональні дані зберігаються локально у зашифрованому сховищі; резервні копії — лише за явною дією користувача. Банки/брокери/Дія можуть отримувати необхідні дані напряму з пристрою, але сервери ОВДП Hub не є посередником для приватних даних, документів чи ключів.

## Перший функціональний зріз

- Next.js / React / TypeScript, статичний export без runtime backend.
- Україномовний адаптивний екран порівняння трьох демонстраційних пропозицій.
- Decimal-розрахунок вартості, НКД, разових комісій, грошових потоків і XIRR ACT/365F.
- Бюджет, цілі лоти, доступний обсяг, залишок коштів.
- Node test runner, перевірка TypeScript, production build і GitHub Actions CI.

## Запуск

Node.js 24+, pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Відкрити http://localhost:3000.

```sh
pnpm test
pnpm typecheck
pnpm build
```

Статичний результат: `apps/web/out`. Не містить приватних даних; можна розмістити на static hosting після окремого рішення про публікацію.

## Структура

- `apps/web` — UI та локальний калькулятор.
- `packages/pricing` — детермінований розрахунковий модуль і тести.
- `docs/architecture.md` — поточна архітектура та межі довіри.
- `docs/product.md` — scope, UX, джерела та критерії приймання.
- `docs/roadmap.md` — наступні етапи.
- `docs/adr/0001-local-first.md` — рішення про локальну приватність.

## Межі моделі

Наразі підтримуються один початковий відтік і наступні невід’ємні надходження. НКД і чисті виплати задаються явно; ринкові конвенції НКД, автоматичні податки, регулярні витрати, FX та реальні котирування ще не реалізовані. Демо має фіксовані дати 22.09.2026–22.09.2027, нульовий податок і відсутність регулярних комісій. XIRR інвестованої позиції не включає залишок бюджету.

Дані НБУ/Мінфіну — заплановані джерела, не підтвердження виконуваної ціни. API партнерів потребують перевірки доступності й умов використання. Підписи, платежі та ордери не входять у поточний scope.
