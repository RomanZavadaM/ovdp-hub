# Реальні пропозиції продавців: перевірка 22.09.2026

Каталог НБУ описує випуски, а не залишки продавців. Непогашений випуск не обов’язково доступний до купівлі. Календар і ставка НБУ не замінюють ціну угоди.

## Перевірені офіційні джерела

- ПриватБанк: https://privatbank.ua/ovdp — публічна таблиця ISIN, погашення, BID/ASK дохідностей та методики SIM/YTM. ASK означає продаж банком клієнту; BID не слід показувати як пропозицію купівлі клієнтом. Рядки з відсутнім ASK не підтверджують продаж. Під час перевірки 22.09.2026 сторінка показувала «Актуально на 11.09.2026». Такий набір є застарілим відносно поточної дати й не може автоматично маркуватися поточним. Кінцева ціна, обсяг і тарифи підтверджуються у Приват24.
- ICU: https://icu.ua/investments і https://icu.ua/about-icu/news/icu-zapustila-pervuyu-v-ukraine-onlayn-platformu-dlya-torgovli-ovgz-v-realnom-vremeni — підтверджують доступ до котирувань та купівлі/продажу в ICU Trade. Публічний документований API котирувань для нашого застосунку не підтверджено.
- Sense: https://help.sensebank.com.ua/uk_UA/4879522845714 — пропозиції та ціна одиниці на момент купівлі показуються у Sense SuperApp. Публічний документований API для агрегатора не підтверджено.

## Наступна інтеграція

Для кожного адаптера необхідні ISIN, продавець, валюта, сторона угоди (ASK для купівлі клієнтом), повна ціна/НКД, мінімальний лот, доступна кількість (або явно unknown), тарифи, дата розрахунку, час джерела, час отримання, строк дії та адреса джерела. Доходність із таблиці без ціни не перетворювати на вигадану ціну.

Стани даних: public indicative, authenticated indicative, executable confirmed. Останній дозволений лише за документацією та підтвердженням партнера. Майбутні/застарілі дати та порожні ASK не трактувати як активні пропозиції. Виключати погашені за датою розрахунку та перевіряти ISIN проти НБУ.

Починати можна з дозволених публічних сторінок/файлів та ручного імпорту пропозицій; стабільний API і право повторного використання перевіряються окремо для кожного продавця. Не обходити вхід у застосунки, не зберігати партнерський спільний секрет у клієнті. Запити — напряму з пристрою, без передавання бюджету, добірок чи нотаток. У версії 0.7 додано окремий розділ «Продавці» та адаптер публічної HTML-таблиці ПриватБанку. Завантаження запускається користувачем напряму з пристрою. Суворо перевіряються заголовки, порядок валют, дати та формат рядків; зміна структури викликає помилку, попередній знімок залишається з повідомленням про невдале оновлення. Погашені випуски не показуються, порожній ASK за замовчуванням відфільтровано. Дані зберігаються в пам’яті сеансу, без автоматичного запису у робочу папку. Публічну дохідність не перетворюємо на ціну планувальника. Повноцінний API, обсяг і виконувана ціна поки відсутні; ICU/Sense не підключені. Парсер перевірений на фактичній структурі публічної сторінки; станом на 22.09.2026 джерело віддавало дату даних 11.09.2026; fixture не постачається як поточні котирування. Право масштабного повторного поширення і стабільний API потребують окремого погодження з продавцем.
