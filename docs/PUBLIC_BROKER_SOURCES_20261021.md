# Публічні пропозиції продавців — 21.10.2026

Статус: окремий продуктовий slice після F5; перевірки й merge — за WORKLOG та Issue #18.

## Що взяли з порівняння OVDP Shell

Корисний підхід — зібрати пропозиції різних майданчиків біля одного ISIN та зберігати походження кожної ціни. Реалізація OVDP Hub написана окремо. Сторонній код, приватні endpoints, збережені паролі/OTP, пошта та автоматизація угод не переносяться.

Перевірені без авторизації офіційні сторінки:

| Джерело | Публічна адреса | Спостережувані поля |
| --- | --- | --- |
| ПриватБанк | https://privatbank.ua/ovdp | ISIN, валюта, погашення, BID/ASK yield, метод, дата таблиці; попередній адаптер збережено |
| Inzhur | https://www.inzhur.reit/offer/ovdp | ISIN, погашення, ціни купівлі/продажу, заявлена дохідність, метод YTM там, де вказаний, опублікована кількість |
| UNIVER | https://www.univer.ua/products | ISIN, валюта, ціна, погашення, заявлена дохідність; метод і кількість не вказані |

Структуру рядків перевірено прямим завантаженням публічних HTML 21.10.2026. Невеликі рядки-fixtures містять лише структуру та опубліковані факти; у них зафіксовано джерело й дату отримання. Значення є тестовим знімком, а не поточною пропозицією.

## Межі даних

- Запити йдуть лише до фіксованих публічних URL. Немає входу в кабінет, виконання JavaScript сторінки чи передачі портфеля/користувацьких ідентифікаторів.
- Грошові поля — Decimal. Ціна, дохідність і кількість — окремі поля. Відсутня ціна/кількість/метод не стають нулем або припущенням.
- Inzhur/UNIVER не дають явного часу актуальності котирування: `sourceDate = null`, freshness unknown. Час завантаження та CMS updatedAt не підміняють дату котирування.
- Спостереження public-indicative. Комісії, повна вартість, виконуваність і доступність угоди не підтверджені. Опублікована кількість є спостереженням сторінки, не резервуванням.
- Об’єднання з каталогом НБУ перевіряє ISIN, валюту та дату погашення. Невідповідні рядки не додаються до інструмента; їх кількість показана окремо.
- Неповний/змінений формат не приймається як порожній успішний каталог. Невелика кількість відхилених рядків відображається, масова зміна структури завершується помилкою.
- Незалежне завантаження провайдерів: збій одного не прибирає іншого. Попередні успішні спостереження лишаються з явною помилкою оновлення та старим retrievedAt.

Наявність публічної сторінки не є підтвердженням партнерства чи доступності приватного API. Умови джерел можуть змінюватися; адаптери обмежені читанням публічної інформації.

## Перевірки

Fixtures з офіційних рядків, відхилення некоректної структури/ціни/дати, незалежні HTTP failures, збереження попередніх даних із помилкою та UI-тексти UK/EN/FR/DE/ES/KO/JA. Далі — exact-head analyze/tests, packaged Windows/macOS smoke, Android release та iOS unsigned.
