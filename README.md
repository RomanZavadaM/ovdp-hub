# ОВДП Hub

Агрегатор публічної інформації про ОВДП України з локальним пошуком і розрахунками.

**Версія 0.2: підключено офіційний довідник НБУ. Ціни брокерів, купівля та персональні рекомендації відсутні. Навчальний калькулятор на /demo використовує лише синтетичні пропозиції.**

## Уже працює

- Довідник ОВДП НБУ: ISIN, валюта, номінал, номінальна ставка, строки та графіки виплат.
- Пошук ISIN, фільтри валюти та непогашених за строком випусків на пристрої.
- Окреме відображення купонів, погашення й дострокового погашення.
- Джерело, час отримання, попередження про старий знімок, обробка помилок і некоректних записів.
- Пряме оновлення пристрій → НБУ за натисканням кнопки; попередній знімок зберігається при помилці.
- Окремий демо-калькулятор: decimal arithmetic, витрати, лоти, ліквідність, XIRR ACT/365F.
- Статичний Next.js / React / TypeScript export; тести, typecheck, build і GitHub CI.

## Приватність

Немає акаунтів, серверної бази портфелів, KYC, аналітики чи завантаження документів. Бюджет, пошукові запити й фільтри залишаються в пам’яті браузера та не зберігаються після перезавантаження.

Оновлення каталогу передає лише запит до фіксованого публічного API НБУ, без credentials і referrer. НБУ бачить звичайні мережеві метадані (зокрема IP). Статичний хостинг також бачить мережеві звернення за файлами. Нашого сервера-посередника немає.

Майбутні приватні портфелі та документи — лише в локальному зашифрованому сховищі. Передавання партнеру — напряму з пристрою за згодою користувача. Приватні дані та ключі не проходять через інфраструктуру ОВДП Hub. Зашифроване сховище ще не реалізовано.

## Запуск

Node.js 24+, pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Відкрити http://localhost:3000. Каталог — /, демо-калькулятор — /demo.

```sh
pnpm test
pnpm typecheck
pnpm build
```

Статичний результат: apps/web/out. Production build і тести не потребують доступу до НБУ.

## Оновлення публічного знімка

```sh
pnpm data:refresh
```

Команда завантажує та перевіряє лише публічні дані. Перед публікацією перегляньте diff apps/web/data/nbu-snapshot.json. При помилці або карантині попередній файл не замінюється.

## Структура

- apps/web — статичний каталог, фільтри та демо-калькулятор.
- packages/market-data — адаптер НБУ, валідація, типи, фільтри, offline-тести.
- packages/pricing — локальний розрахунковий модуль і тести.
- scripts/refresh-nbu.ts — підготовка публічного знімка.
- docs/nbu-source.md — походження, мапінг полів, межі актуальності.
- docs/architecture.md — архітектура та межі довіри.
- docs/product.md — сценарії та критерії приймання.
- docs/roadmap.md — наступні етапи.
- docs/adr/0001-local-first.md — рішення про локальну приватність.

## Межі даних і методики

Номінальна ставка НБУ не є YTM конкретної купівлі. НБУ не надає через цей endpoint цін брокерів або підтвердження виконуваної пропозиції. Час отримання не є датою актуальності самого набору: sourceAsOf залишається null.

Калькулятор підтримує один початковий відтік і невід’ємні надходження. НКД і чисті виплати задаються явно; автоматичний НКД за конвенціями випуску, податки, регулярні витрати та FX ще не реалізовані. Демо має фіксовані дати 22.09.2026–22.09.2027, нульовий податок і відсутність регулярних комісій. XIRR позиції не включає залишок бюджету.

Дані Мінфіну та реальні ціни брокерів — наступні етапи. Умови використання кожного джерела перевіряються окремо.

Джерело довідника: [НБУ — ОВДП](https://bank.gov.ua/ua/markets/ovdp). [Умови відкритих даних](https://bank.gov.ua/ua/open-data).
