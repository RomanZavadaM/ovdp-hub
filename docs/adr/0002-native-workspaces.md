# Flutter і переносні робочі папки

Рішення користувача: один Flutter/Dart продукт для Windows, macOS, Android та iOS. Web/PWA не є цільовою платформою. Попередній TypeScript-прототип виконав роль еталона міграції та після стабілізації Flutter 0.8.2 вилучається з активного дерева; історія лишається в Git.

Робоча папка містить `ovdp-workspace.json` (версія формату), `catalogs/*.json` (незмінні знімки даних НБУ) та `sets/*.json` (назва, нотатки, час і копії випусків). Шлях до неї зберігається лише в конфігурації пристрою. Фінансові суми записуються десятковими рядками.

Desktop: можна відкрити існуючу папку, створити сховище в порожній папці або скопіювати поточні дані до порожньої папки і переключитися. Оригінал не видаляється. Підтримуються доступні файловій системі локальні, мережеві та синхронізовані провайдером папки. Не реалізовано власного хмарного бекенду чи прямого входу в хмарні акаунти.

Мобільні ОС: початкове сховище — приватна папка застосунку. Довготривалий зовнішній доступ потребує Android SAF / iOS security-scoped bookmarks і окремих тестів провайдерів. Звичайний рядок шляху не замінює дозволів ОС; функція не оголошується готовою до реалізації цих адаптерів.

Записи створюються під випадковими унікальними іменами, спочатку як `.pending`, потім перейменовуються у `.json`. Наявні записи не перезаписуються; редагування створює новий варіант. Це зменшує колізії синхронізації, але не гарантує транзакційності довільного мережевого або хмарного провайдера. Автоматичного злиття й видалення історії немає. Некоректні файли спричиняють видиму помилку, а не скидання сховища. Від’єднаний диск не відтворюється автоматично.

Межа приватності: користувач явно дозволив вибір мережевої/хмарної папки. Файли тоді потрапляють до обраного ним провайдера, а не на сервер ОВДП Hub. Поточний формат — відкритий JSON для публічних даних і добірок/нотаток. Документи, секрети, паролі та ключі підпису не належать цьому сховищу. Їх майбутній захист проєктується окремо. Провайдерська синхронізація не є гарантією резервної копії.

Готовність: компіляція, тести й платформна перевірка звітуються окремо. Наявність коду Flutter не означає готовність підписаних пакетів усіх ОС.
