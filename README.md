# ОВДП Hub

Встановлюваний Flutter/Dart-застосунок для огляду ОВДП та власних інвестиційних сценаріїв. Цільові платформи: Windows, macOS, Android, iOS. Web/PWA виключено з продукту.

## Поточна версія 0.7

Активний код — `apps/native`. Перенесено каталог НБУ, пошук і фільтри, графіки виплат, порівняння випусків, короткий/довгий горизонт, збережені добірки з нотатками та навчальний калькулятор. Каталог постачається всередині застосунку й оновлюється напряму з НБУ. Номінальні ставки не є ринковою дохідністю; виконання купівлі немає. Калькулятор явно використовує синтетичний приклад.

Код розділено на UI, Cubit/State та репозиторій даних. Окремі Cubit керують каталогом, редактором добірки, переліком добірок, робочою папкою, калькулятором і навігацією. Стани та вкладені колекції незмінні; віджети не звертаються до файлів чи API. Рішення: `docs/adr/0003-cubit-layers.md`.

Розділ «Планування»: бюджет, валюта, діапазон погашення, резерв та потреба в коштах до конкретної дати. Автоматичний сценарій розподіляє бюджет між різними строками за номіналом; кількість і повну ціну можна змінити вручну. Помісячний календар окремо показує купони й погашення, включно з місяцями без виплат. Сценарії з кількістю, цінами й критеріями зберігаються у робочій папці. Це планування, а не підтвердження доступності на ринку; валюти не змішуються без FX-моделі. У розділі «Продавці» кнопка завантажує публічні котирування ПриватБанку напряму з пристрою: ISIN, валюта, дата погашення, BID/ASK і метод SIM/YTM. Показано дату джерела та попередження про майбутні/не сьогоднішні дані. Це індикативні дохідності, не ціни чи підтверджений залишок. ICU/Sense позначені як ще не підключені. Докладніше — `docs/live-offers.md`.

Планувальник 0.7 додає три режими: розподіл строків, більший прибуток і покриття витрат. Підтримує до 51 витрати, повторення основної потреби ще на п’ять місяців, резерв після кожної потреби та затримку зарахування 0–30 календарних днів. Попередні витрати віднімаються з залишку, дефіцит не зникає. Прибуток — контрактні надходження до погашення мінус повна ціна, без реінвестування, податків і додаткових комісій. Пошук порівнює до восьми жадібних цілочисельних варіантів; це наближений підбір, не доказ глобального максимуму. Усі кандидати обмежуються валютним і часовим фільтром. Можна обмежити пошук лише введеними вручну цінами; інакше він використовує також номінальні оцінки. Режим прибутку не накладає обмежень витрат, режим витрат їх накладає. Достроковий продаж не моделюється.

Виправлено Unicode заголовка Windows: явні Unicode-коди та UTF-8 для C++ компілятора.

Тестові пакети містять одну кореневу папку `OVDP-Hub-<version>-b<build>-<platform>-<run>-<commit>`. Розпаковуйте весь пакет і запускайте застосунок із цієї папки. Версії програмних файлів не змішуються; робоча папка з даними зберігається окремо.

Звичайні добірки формату 1 сумісні з попередніми версіями. Сценарії використовують формат добірки 2. Нові плани з кількома витратами мають внутрішню версію сценарію 2 та потребують застосунку 0.7; версія 0.6 відмовиться відкривати такий план. Версія 0.7 читає попередні сценарії. Версія 0.5 не зможе прочитати таку робочу папку; для паралельного тестування використовуйте копію папки.

## Робоча папка

Каталоги та добірки зберігаються на пристрої у переносному форматі JSON. На desktop можна відкрити іншу папку або скопіювати поточну до нового місця, зберігши оригінал. Підтримуються шляхи локальної файлової системи, підключені мережеві диски та папки хмарних клієнтів. Хмарні файли синхронізує обраний користувачем провайдер. ОВДП Hub не має сервера приватних даних.

Добірка містить копію випусків на момент збереження; оновлення НБУ не змінює минулих сценаріїв. Нові варіанти зберігаються окремо. Пошкоджені файли чи недоступний диск показуються як помилка. Автоматичного злиття синхронізованих змін немає.

JSON поки не зашифрований. Документи, ключі підпису та облікові секрети не належать цьому сховищу. На телефонах поки використовується внутрішня папка: Android SAF та iOS файлові провайдери ще потребують реалізації й перевірки. Портфелі, підписи, KYC, партнерські операції та аналітичне стеження не реалізовані.

## Для розробника

Flutter 3.47.5 / Dart 3.13.4. Кінцевому користувачеві SDK або локальний сервер не потрібні.

```sh
cd apps/native
flutter pub get
flutter analyze
flutter test
flutter build windows --release
```

Інші цілі: `flutter build macos --release`, `flutter build apk --release`, `flutter build ipa --release`. Windows потребує Visual Studio C++ desktop tooling; Apple — macOS/Xcode та відповідного підпису для поширення; Android — SDK/JDK і release-keystore. Збірки та підписи кожної ОС перевіряються окремо. Наявність конфігурації не означає готовність магазинного релізу.

Windows-пакет повинен містити весь каталог `build/windows/x64/runner/Release`, включно з DLL і ресурсами, а не один exe.

## Структура

- `apps/native/lib` — Flutter інтерфейс, дані, сховище, фінансові розрахунки.
- `apps/native/test` — контрольні фінансові приклади й тести збереження/перенесення даних.
- `apps/native/assets` — публічний початковий знімок НБУ.
- `docs/adr/0002-native-workspaces.md` — рішення про платформи, робочі папки та межі приватності.
- `docs/platforms.md` — способи пакування.
- `apps/web`, `apps/mobile`, `apps/desktop`, `packages` — попередній TypeScript-прототип як еталон міграції. Не є активними продуктами для поширення.

Джерело каталогу: https://bank.gov.ua/ua/markets/ovdp. Час завантаження знімка не є датою актуальності всього набору НБУ.
