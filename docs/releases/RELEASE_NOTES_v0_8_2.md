# OVDP Hub 0.8.2

**Дата релізу:** 22.09.2026  
**Статус:** prerelease / stabilization checkpoint  
**Правовласник:** © 2026 Roman Zavada (Роман Завада). All rights reserved.

## Мета

0.8.2 консолідує репозиторій навколо єдиного Flutter-продукту перед наступним великим етапом «Ринок».

## Що входить

- архітектура, product docs і roadmap синхронізовані з Flutter/Dart;
- завершені Next.js/Expo/Tauri/TypeScript прототипи прибрані з активного дерева, історія лишається в Git;
- старий TS refresh НБУ замінено на Dart tool;
- формалізовано provenance/freshness для НБУ, Мінфіну та продавців;
- додано threat model для майбутнього encrypted vault і backup/recovery;
- локальний кеш публічних каталогів має retention, а збережені сценарії лишають власні копії потрібних випусків;
- додано основу багатомовності: українська — default/canonical; оболонка дозволяє вибрати English, Français, Deutsch, Español, 한국어, 日本語.

## Сумісність

Версія workspace marker і формати вже збережених добірок/сценаріїв не змінюються. 0.8.2 не переписує наявні приватні файли користувача.

## Межі

Не додаються брокерське виконання, KYC, центральне зберігання портфеля або private relay. Успішний HTTP-відгук не прирівнюється до актуальності ринкових даних.
